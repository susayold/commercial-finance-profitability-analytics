# Claim Governance

## Evidence classes

| Class | Definition | Allowed wording |
|---|---|---|
| OBSERVED | Traceable public report, audited statement or official source | “The FY2020 audited statement reports…” |
| SIMULATED | Fictional VietNova operating ledger or event | “The modeled case shows…” |
| DERIVED | Formula calculated from observed or simulated inputs | “Calculated margin is…” |
| ASSUMPTION | Forecast, scenario, elasticity, allocation or recommendation input | “Assuming…, the scenario indicates…” |
| RECOMMENDATION | Management action based on evidence | “Recommend…, monitored by…” |

## CV and interview rules

- Never say the model increased a real company's profit.
- Use “simulated impact”, “modeled case” or “estimated under stated assumptions”.
- State the comparison period and revenue basis for peer metrics.
- Keep source URL and page anchor close to every material external fact.
- Disclose synthetic data before showing impressive numbers.
- Do not claim causal promotion uplift without a counterfactual.
- Do not rank peers on CAGR across definition or consolidation breaks without re-normalisation.

## Review checklist

Before publication, confirm:

1. Every KPI has an evidence class.
2. Every external number has a source.
3. Every scenario impact has assumptions.
4. Every recommendation has a monitoring KPI and owner.
5. Every limitation that could change the decision is visible.
6. The public website, CV, deck and memo use the same evidence language.
