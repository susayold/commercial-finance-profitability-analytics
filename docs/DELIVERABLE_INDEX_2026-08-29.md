## Integrity and storage policy

- Public filings and source registry are archived in the private Drive project folder; raw reports are excluded from Git history.
- Granular VietNova operating data is deterministic synthetic data and is labelled as synthetic in the model, deck and website.
- Every calculated output is formula-driven or reproducible from versioned scripts.
- Local staging is disposable; remote GitHub / Drive / Sites copies are the authoritative archive.
