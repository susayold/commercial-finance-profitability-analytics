# VietNova Power BI refresh fixture

This folder contains the deterministic, synthetic 14-file input fixture used by
the editable Power BI PBIP/PBIT package. It is intentionally committed so the
GitHub repository and the Drive bundle have the same reproducible starting
point.

- Dataset: VietNova synthetic v1.0.0
- Period: January 2023–December 2025 (36 months)
- Grain: 6,480 sales lines, 36 SKUs, 5 channels, 24 customers
- Refresh contract: keep the 14 filenames, headers and key rules unchanged;
  point the `DataRoot` parameter to this folder (or a replacement folder), then
  refresh in Power BI Desktop.

The rows are synthetic and are not presented as live company data. To create a
new deterministic fixture, run:

```powershell
python scripts/generate_vietnova_data.py --output-dir powerbi/data/current
```

`source_control.csv` is the model's refresh/evidence control table and is
generated by `create_source_control` in
`scripts/build_powerbi_refreshable_project.py`.
