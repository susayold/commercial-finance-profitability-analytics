# VietNova Power BI refresh fixture

This folder contains the deterministic input fixture used by
the editable Power BI PBIP/PBIT package. It is intentionally committed so the
GitHub repository and the Drive bundle have the same reproducible starting
point.

- Dataset: VietNova synthetic v1.0.0
- Period: January 2023–December 2025 (36 months)
- Grain: 6,480 sales lines, 36 SKUs, 5 channels, 24 customers
- Refresh contract: keep the 19 filenames, headers and key rules unchanged;
  point the `DataRoot` parameter to this folder (or a replacement folder), then
  refresh in Power BI Desktop.

The operating rows are synthetic and are not presented as live company data;
the peer benchmark file contains approved public reported statement values and
the peer queue intentionally preserves review-required candidates. To create
a new deterministic operating fixture, run:

```powershell
python scripts/generate_vietnova_data.py --output-dir powerbi/data/current
```

`source_control.csv` is the model's refresh/evidence control table and is
generated by `create_source_control` in
`scripts/build_powerbi_refreshable_project.py`.

The additional planning/evidence files are:

- `scenario_selector.csv` — disconnected Actual/Budget/Forecast/Upside/Downside
  selector used by the scenario measures.
- `opex_headcount_planning_synthetic.csv` — cost-centre headcount and
  actual/budget/forecast OPEX bridge.
- `capex_fixed_asset_planning_synthetic.csv` — project approval, commitment,
  cash payment, depreciation, benefit and payback bridge.
- `peer_benchmark_approved_2016_2025.csv` — approved reported peer panel.
- `peer_extraction_queue.csv` — candidates that remain visibly review-gated.
