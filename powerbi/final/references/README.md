# Reference screen pack

These PNGs are the user-provided Power BI screenshots used as the visual specification for page hierarchy, canvas geometry, navy/teal palette, filter placement, KPI cards, evidence banners and table density. They are references only; no values are copied into the dynamic model.

`00_executive.png` through `09_valuation_mna.png` map to the 10 screenshot variants supplied with the build request. The final report keeps dynamic values in measures and source queries.
